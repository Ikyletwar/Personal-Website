## 📖 Tentang Saya

Hai! Saya **Hizkia Letwar**, seorang siswa kelas 10 di **SMK Negeri 1 Maluku Tengah**, jurusan **Teknik Jaringan Komputer dan Telekomunikasi (TJKT)**. Saat ini saya juga menjabat sebagai **Anggota OSIS Bidang IT**, di mana saya bertanggung jawab untuk mengelola dan mengembangkan sistem teknologi informasi di sekolah.

### 🎯 Perjalanan Saya

Perjalanan saya di dunia teknologi dimulai ketika **ChatGPT pertama kali rilis** sebagai LLM yang benar-benar capable. Sejak saat itu, saya mulai mengeksplorasi apa yang saya sebut **"Vibe Coding"** — sebuah pendekatan development di mana AI mengubah ide dalam bahasa alami menjadi kode yang berfungsi.

Ini memungkinkan saya untuk:
- 🧠 **Fokus pada kreativitas** dan pemecahan masalah, bukan sekadar sintaks
- ⚡ **Prototype lebih cepat** dari ide ke implementasi
- 🎨 **Eksplorasi lebih banyak** kemungkinan desain dan arsitektur
- 📚 **Belajar lebih dalam** tentang konsep, bukan hanya kode

### 💡 Filosofi Saya

Saya percaya bahwa **elegansi bukan hanya soal estetika** — ini tentang menciptakan solusi yang:

| Prinsip | Deskripsi |
|---------|-----------|
| 🎨 **Bersih** | Kode dan desain yang mudah dipahami dan dipelihara |
| ⚡ **Fungsional** | Setiap elemen memiliki tujuan dan bekerja dengan baik |
| 🧠 **Thoughtful** | Dipikirkan dengan matang, bukan sekadar ikut tren |
| 🌍 **Scalable** | Dirancang untuk tumbuh bersama kebutuhan |
| ♿ **Aksesibel** | Dapat digunakan oleh semua orang, tanpa terkecuali |

> **"Elegance Is My Philosophy"** — Ini bukan sekadar tagline. Ini adalah cara saya mendekati setiap proyek, setiap baris kode, dan setiap desain yang saya buat.

## 🛠️ Stack Teknologi

Saya memilih untuk **tidak menggunakan framework** dalam proyek ini. Alasannya sederhana:

> **"Gunakan tool yang tepat untuk pekerjaan yang tepat."**

Untuk portofolio sederhana seperti ini, **vanilla HTML, CSS, dan JavaScript** sudah lebih dari cukup. Tidak perlu React, tidak perlu Vue, tidak perlu build process yang rumit.

### 📚 Teknologi Inti

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐      │
│  │   HTML5     │  │    CSS3     │  │ JavaScript  │      │
│  │   (Struktur)│  │   (Styling) │  │  (Logic)    │      │
│  └─────────────┘  └─────────────┘  └─────────────┘      │
│         ↓                ↓                ↓              │
│  Semantic HTML    Custom Props     Vanilla JS           │
│  ARIA Labels      Flexbox/Grid     Intersection Obs.    │
│  Meta Tags        Animations       Event Listeners      │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 🎨 CSS Features yang Saya Gunakan

| Kategori | Fitur |
|----------|-------|
| **Layout** | Flexbox, CSS Grid, Multi-column |
| **Styling** | Custom Properties, Calc(), Clamp() |
| **Animasi** | Keyframes, Transitions, Transform |
| **Effects** | Backdrop Filter, Box Shadow, Gradient |
| **Responsive** | Media Queries, Container Queries |

## 🚀 Memulai

### 📥 Clone / Download

```bash
# Clone repository ini
git clone https://github.com/Ikyletwar/Personal-Website.git

# Masuk ke folder proyek
cd Personal-Website
```

### 🌐 Menjalankan Lokal

**Opsi 1: Buka Langsung di Browser**
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

**Opsi 2: Gunakan Local Server (Recommended)**

```bash
# Python 3
python -m http.server 8000

# Node.js (npx)
npx serve

# PHP
php -S localhost:8000

# Live Server (VS Code Extension)
# Klik kanan pada index.html → "Open with Live Server"
```

Kemudian buka `http://localhost:8000` di browser.

### 📦 Deployment

Website ini **ready to deploy** ke platform manapun:

#### GitHub Pages

```bash
# Pastikan sudah di branch main
git push origin main

# Kunjungi:
# https://github.com/Ikyletwar/Personal-Website/settings/pages
# Aktifkan GitHub Pages dari branch main
```

#### Vercel

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel

# Deploy ke production
vercel --prod
```

#### Netlify

```bash
# Drag & drop folder ke https://app.netlify.com/drop
# Atau connect GitHub repository untuk auto-deploy
```

#### Manual Upload

Upload file `index.html` ke:
- Hosting tradisional (cPanel, etc.)
- Cloud storage dengan static hosting
- CDN seperti Cloudflare Pages

## 🤔 FAQ (Pertanyaan yang Sering Diajukan)

### ❓ Apa itu "Vibe Coding"?

**Vibe Coding** adalah istilah yang saya gunakan untuk menggambarkan pendekatan development di mana:
- Saya menggunakan **AI sebagai pair programmer**
- Fokus pada **ide dan kreativitas**, bukan sintaks
- AI membantu **mengubah prompt** menjadi kode yang berfungsi
- Proses development lebih **cepat dan enjoyable**

Tools yang saya gunakan untuk Vibe Coding:
- Trae AI
- Qwen Code CLI
- ChatGPT
- Gemini

### ❓ Kenapa tidak menggunakan framework seperti React?

Untuk portofolio sederhana seperti ini, **vanilla HTML/CSS/JS sudah cukup**. Pertimbangan saya:

| Faktor | Vanilla | React |
|--------|---------|-------|
| Bundle Size | ~84KB | ~150KB+ |
| Build Process | ❌ Tidak perlu | ✅ Perlu |
| Learning Curve | ✅ Mudah | ⚠️ Medium |
| Performance | ✅ Excellent | ⚠️ Good |
| Complexity | ✅ Simple | ⚠️ Overkill |

Saya percaya: **"Gunakan tool yang tepat untuk pekerjaan yang tepat."**

### ❓ Apakah saya bisa menggunakan template ini?

**Tentu saja!** Saya sangat mendukung siapa saja yang ingin menggunakan atau memodifikasi template ini untuk portofolio mereka sendiri.

Yang saya minta:
1. ✅ Berikan kredit jika menggunakan design yang sama
2. ✅ Jangan claim sebagai karya original Anda
3. ✅ Feel free to customize sesuai kebutuhan

### ❓ Bagaimana cara deploy ke GitHub Pages?

```bash
# 1. Pastikan file sudah di-commit
git add .
git commit -m "Ready for deployment"

# 2. Push ke GitHub
git push origin main

# 3. Aktifkan GitHub Pages
# Settings → Pages → Source: Deploy from branch → main → Save

# 4. Website akan live di:
# https://username.github.io/nama-repo
```

### ❓ Apakah ada versi dark/light mode toggle?

Saat ini **hanya dark mode** yang tersedia. Ini adalah pilihan desain intentional karena:
- Dark mode lebih elegan untuk portofolio
- Mengurangi eye strain
- Lebih hemat baterai di OLED screens

Namun, Anda bisa menambahkan light mode toggle dengan memodifikasi CSS custom properties!
